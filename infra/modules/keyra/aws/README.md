# Keyra on AWS

Runs one Keyra instance on ECS Fargate behind an Application Load Balancer, on your domain or behind CloudFront
without one, with RDS for PostgreSQL or your own Postgres. See the repository README's "Deploy to AWS" section for
the walkthrough and database/network modes, and `infra/examples/aws` for a root module that calls this one.

The tables below are generated by `terraform-docs infra/modules/keyra/aws`; edit descriptions in
`variables.tf` / `outputs.tf`, not here.

| db\_pool\_size | Connections each task opens (KEYRA\_DB\_POOL\_SIZE). | `number` | `10` | no |

| deletion\_protection | Protects the RDS instance and the load balancer from terraform destroy, keeps a final RDS snapshot, and gives deleted secrets a 30-day recovery window. | `bool` | `true` | no |
| domain\_name | Hostname Keyra serves on, e.g. keyra.example.com: the URL https://<domain\_name> is also the token issuer. null puts CloudFront in front instead and serves on its https://<id>.cloudfront.net URL, with the load balancer internal. | `string` | `null` | no |
| egress | How tasks reach the database and the internet. Default: the module's VPC, with tasks in public subnets (public IPs, reachable only from the load balancer) and RDS in private subnets. static\_ip = true moves tasks to private subnets behind a NAT gateway with an Elastic IP, for databases that allowlist clients (see the egress\_ip output). vpc\_id + task\_subnet\_ids + alb\_subnet\_ids deploy into your own VPC, for a private external database: tasks get no public IP, so the task subnets need their own route out (NAT) to pull the image and reach AWS APIs. The load balancer subnets span two or more AZs: public with domain\_name, private (no internet gateway route, in a VPC that has one) without it, for CloudFront's VPC origin. | ```object({ static_ip = optional(bool, false) vpc_id = optional(string) task_subnet_ids = optional(list(string)) alb_subnet_ids = optional(list(string)) })``` | `{}` | no |
| external\_database | Bring your own Postgres instead of RDS. null (default) creates RDS. jdbc\_url must require TLS (sslmode=require, verify-ca or verify-full). password\_secret\_id is the ARN of an existing Secrets Manager secret holding only the password; the module only grants read access to it and never sees the value. A secret encrypted with your own KMS key also needs kms:Decrypt for the execution role. | ```object({ jdbc_url = string username = string password_secret_id = string })``` | `null` | no |
| image | Custom Keyra container image, e.g. <account>.dkr.ecr.<region>.amazonaws.com/keyra:1.0.0. null runs the published release from GHCR. | `string` | `null` | no |
| jwt\_key\_version | Bump to generate a new JWT signing key. Existing access tokens stop verifying (they live 15 minutes). | `number` | `1` | no |
| max\_replicas | Autoscaling ceiling. max\_replicas x db\_pool\_size must fit within the database's max\_connections. | `number` | `4` | no |
| metrics\_enabled | Exports metrics to CloudWatch (namespace Keyra) through an AWS Distro for OpenTelemetry collector sidecar. The sidecar shares the task's existing CPU and memory; CloudWatch bills per custom metric. | `bool` | `false` | no |
| postgres\_version | RDS for PostgreSQL engine version, e.g. 18 or 18.1. Ignored when external\_database is set. | `string` | `"18"` | no |
| replicas | Minimum number of running tasks. Two or more for availability. | `number` | `2` | no |
| route53\_zone\_id | Route 53 hosted zone that contains domain\_name. The module adds the ACM validation and alias records to it. Set together with domain\_name. | `string` | `null` | no |

## Outputs

| Name | Description |
| ---- | ----------- |
| alb\_dns\_name | Load balancer hostname: what domain\_name points at, or the internal origin behind CloudFront. |
| app\_databases | Per app database: name, user, password secret and JDBC URL. Empty with an external database. |
| bootstrap\_admin\_password\_secret | Secrets Manager secret name holding the first admin's password. |
| egress\_ip | Static outbound IP to allowlist on an external database. null unless egress.static\_ip. |
| rds\_endpoint | RDS hostname. null with an external database. |
| task\_security\_group\_id | Security group of the tasks: allow it on an external database's security group or firewall. |
| task\_subnet\_ids | Subnets the tasks run in. |
| url | Public HTTPS URL of the instance (also the token issuer). |
| vpc\_id | VPC the tasks run in; attach your own apps here to reach the database. |
