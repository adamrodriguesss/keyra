# Keyra on GCP

Runs one Keyra instance on Cloud Run, with Cloud SQL or your own Postgres. See the repository README's
"Deploy to GCP" section for the walkthrough and database/network modes, and `infra/examples/gcp` for a root
module that calls this one.

The tables below are generated by `terraform-docs infra/modules/keyra/gcp`; edit descriptions in
`variables.tf` / `outputs.tf`, not here.

## Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| bootstrap\_admin\_email | First admin, created at startup when no managers exist. | `string` | n/a | yes |
| bootstrap\_admin\_password | First admin's password (12-128 characters). Ephemeral: written to Secret Manager, never to state. Supply via TF\_VAR\_bootstrap\_admin\_password. | `string` | n/a | yes |
| image | Keyra container image, e.g. europe-west1-docker.pkg.dev/<project>/keyra/keyra:1.0.0. | `string` | n/a | yes |
| name | Instance name. Prefixes every resource; the Cloud Run service gets exactly this name. | `string` | n/a | yes |
| project\_id | GCP project to deploy into. | `string` | n/a | yes |
| region | Region for Cloud Run, Cloud SQL and the network, e.g. europe-west1. | `string` | n/a | yes |
| app\_databases | Extra databases for your own apps on the Cloud SQL instance: one database and one user per key (same name), password in Secret Manager. Bump password\_version to rotate. Cloud SQL only. | ```map(object({ password_version = optional(number, 1) }))``` | `{}` | no |
| cloud\_sql\_version | Cloud SQL Postgres version. Ignored when external\_database is set. | `string` | `"POSTGRES_18"` | no |
| db\_password\_version | Bump to generate a new Cloud SQL password. Ignored when external\_database is set. | `number` | `1` | no |
| db\_pool\_size | Connections each instance opens (KEYRA\_DB\_POOL\_SIZE). | `number` | `10` | no |
| db\_tier | Cloud SQL machine tier. Ignored when external\_database is set. | `string` | `"db-custom-1-3840"` | no |
| deletion\_protection | Protects the Cloud SQL instance and the Cloud Run service from terraform destroy. | `bool` | `true` | no |
| egress | How Cloud Run reaches the database. Default: Cloud SQL over the module's VPC, or a public external database over the internet. static\_ip = true routes all egress through Cloud NAT with a reserved IP, for databases that allowlist clients (see the egress\_ip output). network + subnetwork send egress into your own VPC, for a private external database; you own its routing and firewall rules. | ```object({ static_ip = optional(bool, false) network = optional(string) subnetwork = optional(string) })``` | `{}` | no |
| external\_database | Bring your own Postgres instead of Cloud SQL. null (default) creates Cloud SQL. jdbc\_url must require TLS (sslmode=require, verify-ca or verify-full). password\_secret\_id is an existing Secret Manager secret holding only the password ("projects/<p>/secrets/<s>" or a secret name in this project); the module only grants read access to it and never sees the value. | ```object({ jdbc_url = string username = string password_secret_id = string })``` | `null` | no |
| jwt\_key\_version | Bump to generate a new JWT signing key. Existing access tokens stop verifying (they live 15 minutes). | `number` | `1` | no |
| max\_replicas | Autoscaling ceiling. max\_replicas x db\_pool\_size must fit within the database's max\_connections. | `number` | `4` | no |
| replicas | Minimum number of running instances. Two or more for availability. | `number` | `2` | no |
| subnet\_cidr | Range for the module VPC's Cloud Run subnet (only created for Cloud SQL or static\_ip). | `string` | `"10.10.0.0/24"` | no |

## Outputs

| Name | Description |
| ---- | ----------- |
| app\_databases | Per app database: name, user, password secret and JDBC URL. Empty with an external database. |
| cloud\_sql\_instance | Cloud SQL connection name. null with an external database. |
| cloud\_sql\_private\_ip | Private IP of the Cloud SQL instance. null with an external database. |
| egress\_ip | Static outbound IP to allowlist on an external database. null unless egress.static\_ip. |
| service\_account\_email | Identity Cloud Run runs as. |
| url | Public HTTPS URL of the instance (also the token issuer). |
| vpc\_network | Network Cloud Run egresses into; attach your own apps here to reach the database. |
| vpc\_subnetwork | Subnetwork Cloud Run egresses into (Direct VPC egress). |
